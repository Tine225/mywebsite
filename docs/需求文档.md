# 个人网站 · 需求文档

## 1. 项目概述

本项目是一个**个人网站**，用于对外展示个人信息、技能与项目作品。网站包含两部分：

1. **前台展示页**：任何访客都可以浏览，展示个人资料、技能、项目。
2. **后台管理**：网站所有者以管理员身份登录后，可在线增删改上述内容，无需改代码或重新部署。

网站最终通过**自定义域名**公开访问。

## 2. 背景与目标

- **背景**：需要一个简单、低成本、易维护的个人主页，展示个人形象与作品。
- **目标**：
  - 前台能展示个人信息、技能、项目；
  - 管理员能在网页后台登录并在线修改内容；
  - 别人能通过域名访问；
  - 技术实现简单，可用免费额度运行，长期维护成本低。

## 3. 用户角色

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 访客 | 任何打开网站的人 | 只读浏览前台内容 |
| 管理员（网站所有者） | 通过密码登录后台 | 登录、增删改全部内容 |

## 4. 功能需求

### 4.1 前台展示

| 页面 | 路径 | 内容 |
| --- | --- | --- |
| 首页 | `/` | 头像、姓名、职位、个人简介、邮箱、所在地、社交链接；提供「技能」「项目」入口卡片 |
| 技能页 | `/skills` | 按分类分组展示技能名称与熟练度进度条（0–100） |
| 项目页 | `/projects` | 项目卡片：封面图、标题、描述、标签、在线/源码链接、「精选」标记，精选项目优先展示 |

全局组件：顶部导航栏（首页/技能/项目）、页脚（版权信息 + 「管理员登录」入口）。

### 4.2 后台管理

| 功能 | 说明 |
| --- | --- |
| 登录 | 访问 `/admin/login`，输入管理员密码登录 |
| 个人信息编辑 | 修改姓名、职位、简介、邮箱、所在地、头像 URL |
| 社交链接编辑 | 增删改社交链接（名称 + URL） |
| 技能编辑 | 增删改技能（名称、分类、熟练度 0–100） |
| 项目编辑 | 增删改项目（标题、描述、封面、在线/源码地址、标签、是否精选） |
| 保存 | 点击「保存」后写入存储，前台页面立即反映最新内容 |

### 4.3 认证与安全

- 管理员通过**密码**登录；
- 登录成功后发放**会话 Cookie**，有效期 7 天；
- 未登录访问后台自动跳转到登录页；
- 内容**写接口**必须鉴权，未登录返回 401；
- 密码不落地明文，登录校验使用哈希 + 恒定时间比较。

### 4.4 部署与域名

- 部署平台：**Netlify**（免费额度）；
- 数据持久化：**Neon**（Postgres 云数据库，免费额度）；
- 上线后先使用平台默认域名（如 `xxx.netlify.app`），后续可绑定**自定义域名**。

## 5. 非功能需求

- **简单易维护**：技术栈单一（Next.js），无复杂基础设施；
- **免费可运行**：部署与数据库均可用免费额度覆盖个人站点流量；
- **内容与代码分离**：修改内容走后台，不触碰代码、无需重新部署；
- **基础安全**：密码不明文存储、写操作鉴权、会话有有效期。

## 6. 数据模型

所有内容统一存储为一个 JSON 文档（`SiteContent`）：

```ts
type SocialLink = { id: string; label: string; url: string };

type Profile = {
  name: string;
  title: string;
  bio: string;
  avatar: string;      // 头像图片 URL，可为空
  email: string;
  location: string;
  socials: SocialLink[];
};

type Skill = { id: string; name: string; level: number; category: string };

type Project = {
  id: string;
  title: string;
  description: string;
  image: string;   // 封面图 URL，可为空
  link: string;    // 在线地址，可为空
  github: string;  // 源码地址，可为空
  tags: string[];
  featured: boolean;
};

type SiteContent = { profile: Profile; skills: Skill[]; projects: Project[] };
```

## 7. 页面与接口清单

**页面**：`/`、`/skills`、`/projects`、`/admin/login`、`/admin`

**接口**：

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/auth/login` | 否 | 密码登录，成功返回会话 Cookie |
| POST | `/api/auth/logout` | 否 | 清除会话 Cookie |
| GET | `/api/content` | 否 | 获取站点内容 |
| PUT | `/api/content` | 是 | 校验并保存站点内容 |

## 8. 验收标准

- 访客可正常浏览首页、技能页、项目页，内容完整美观；
- 管理员可用密码登录后台，修改后前台立即更新；
- 未登录访问 `/admin` 被重定向到登录页，未登录调用写接口返回 401；
- 线上站点可通过域名访问，数据持久化（重新部署不丢内容）。
